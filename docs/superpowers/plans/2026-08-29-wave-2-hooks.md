# Волна 2. Хуки — план реализации

> **Исполнителю:** обязательный под-скилл — `superpowers:subagent-driven-development`
> либо `superpowers:executing-plans`. Шаги отмечаются чекбоксами.

**Цель:** плагин перехватывает пять моментов жизни сессии, блокирует поломку
и выход за границу репозитория, предупреждает о нарушении конвенции — и ни
разу не выглядит разрешившим, когда на самом деле не смог.

**Архитектура:** `hooks.json` → `hook.sh <событие>` (шим, ~10 строк) →
`hook.py <событие>` (вся логика). Гейты волны 1 импортируются модулями.

**Стек:** Python 3 stdlib, POSIX sh, git. Ноль зависимостей.

**Спека:** `docs/superpowers/specs/2026-08-29-wave-2-hooks-design.md`
**Критерии выхода:** `docs/roadmap.md`, «Волна 2»

## Что уже проверено и не переоткрывается

Контракт хуков сверен с документацией, не по памяти. Опираться на это можно:

| факт | следствие для кода |
|---|---|
| рабочий каталог процесса хука не документирован; `cwd` приходит в stdin | **никогда `os.getcwd()`**. Корень ищется от `cwd` из stdin, запасной вариант — `CLAUDE_PROJECT_DIR` |
| имена полей `tool_input` для `Write`/`Edit` не документированы | путь достаётся защитно; не нашёлся — видимая строка и код 0 |
| stdout уходит в контекст только у `SessionStart`, `UserPromptSubmit`, `UserPromptExpansion` | сводка — в stdout; всё остальное агенту — stderr при коде 2 |
| код 2 = блок, stderr идёт агенту; любой другой ненулевой = небл окирующая ошибка | «не смог» обязан быть кодом 0 плюс видимая строка, а не ненулевым кодом |
| хуки одного события идут параллельно, побеждает самый строгий | ни одно правило не вправе опираться на порядок |
| `stop_hook_active` есть; сверх него Claude Code сам сдаётся после восьми блокировок | наш хук обязан сдаться сам на втором заходе |
| матчер — регулярка, если содержит что-то вне `[a-zA-Z0-9_\- ]` | `Edit\|NotebookEdit\|Write` законен |

import json
import os
import subprocess
import sys
import unittest
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
SHIM = ROOT / "hooks" / "hook.sh"


def run_hook(event, payload, env=None, cwd=None):
    """Хук всегда прогоняется настоящим подпроцессом.

    Вызов логики напрямую не проверяет ни shim, ни код возврата, ни разбор
    stdin — то есть ровно то, что ломается на практике.
    """
    environ = dict(os.environ)
    environ.update(env or {})
    return subprocess.run(
        [str(SHIM), event],
        input=json.dumps(payload),
        capture_output=True, text=True,
        cwd=str(cwd or ROOT), env=environ,
    )


class TestEntryContract(unittest.TestCase):
    def test_shim_is_executable(self):
        self.assertTrue(os.access(SHIM, os.X_OK), "hook.sh не исполняем")

    def test_unknown_event_is_not_a_violation(self):
        """Незнакомое событие — не нарушение: код 0 и видимая причина."""
        result = run_hook("OnFullMoon", {"hook_event_name": "OnFullMoon"})
        self.assertEqual(result.returncode, 0)
        self.assertIn("OnFullMoon", result.stdout + result.stderr)

    def test_broken_stdin_is_not_a_violation(self):
        """Битый JSON на входе — «не смог», а не «запретил»."""
        result = subprocess.run([str(SHIM), "PreToolUse"], input="{не json",
                                capture_output=True, text=True, cwd=str(ROOT))
        self.assertEqual(result.returncode, 0)
        self.assertIn("не разобран", result.stderr)

    def test_missing_interpreter_is_visible_and_not_a_violation(self):
        """Нет python — код 0 и строка с причиной, никогда не тишина.

        Урок оплачен чужой болью: хук возвращал 1 из-за отсутствия flock
        на macOS, это читалось как «занято», и автокоммиты молча отключились
        у всех пользователей macOS.
        """
        env = {"TWINKLE_PYTHON": "/nonexistent/python3"}
        result = run_hook("SessionStart", {"hook_event_name": "SessionStart"}, env=env)
        self.assertEqual(result.returncode, 0)
        self.assertIn("гейт не выполнился", result.stderr)


class TestNoSilencing(unittest.TestCase):
    """Три шаблона, которыми отказ превращают в тишину. Запрещены дословно."""

    def test_shim_never_silences(self):
        text = SHIM.read_text(encoding="utf-8")
        for banned in ("2>/dev/null", "|| true", ">/dev/null 2>&1"):
            self.assertNotIn(banned, text, banned)

- [x] **Step 3: Реализация — `hooks/hook.sh`**

> **Дефект плана, исправлен при исполнении.** Проба интерпретатора в снимке
> ниже гасила обе струи вывода — и ровно эта запись стоит третьей в списке
> шаблонов, дословно запрещённых тестом Step 1. План противоречил сам себе:
> реализация из Step 3 краснела на тесте из Step 1. Поставлена подстановка
> команды (`RESOLVED=$(command -v "$PY")`): stdout забирается ею самой,
> перенаправление не нужно, контракт «не смог ≠ разрешил» не меняется.
> Отдельно: запрещённые шаблоны не называются даже в комментариях `hook.sh` —
> тест читает файл буквально, и файл находил сам себя. Смотреть поставленное
> — `hooks/hook.sh`, а не снимок ниже.

```sh
#!/bin/sh
# Единственная работа шима — не дать «не смог» выглядеть как «разрешил».
# Если python отсутствует или падает при импорте, здесь печатается видимая
# строка с причиной и возвращается 0: код 2 означает нарушение, и только его.
# Переменная нужна тесту, чтобы подсунуть заведомо отсутствующий интерпретатор.
PY="${TWINKLE_PYTHON:-python3}"
DIR=$(dirname "$0")

RESOLVED=$(command -v "$PY")
if [ -z "$RESOLVED" ] && [ ! -x "$PY" ]; then
    echo "гейт не выполнился: интерпретатор $PY не найден" >&2
    exit 0
fi

"$PY" "$DIR/hook.py" "$@"
CODE=$?
if [ $CODE -ne 0 ] && [ $CODE -ne 2 ]; then
    echo "гейт не выполнился: hook.py вернул $CODE" >&2
    exit 0
fi
exit $CODE
```

- [x] **Step 4: Реализация — `hooks/hook.py`, каркас**

```python
#!/usr/bin/env python3
"""Единственная точка логики хуков.

Одна таблица зон, один разбор stdin, одна точка отказа. У изученного аналога
три разошедшиеся таблицы зон и две копии парсера JSON, одна из которых не
исполняется никогда, потому что установлен `jq`.

Коды: 2 — нарушение, 0 — всё остальное, включая «не смог», у которого всегда
есть видимая строка причины (секция 15 спеки).
"""

import json
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent))

from scripts.findings import EXIT_OK, EXIT_VIOLATION


def read_event(stream):
    """Событие и полезная нагрузка из stdin. Битый JSON — не нарушение."""
    raw = stream.read()
    try:
        return json.loads(raw) if raw.strip() else {}
    except json.JSONDecodeError as error:
        raise ValueError("вход не разобран: %s" % error)


def main(argv=None):
    argv = list(sys.argv[1:] if argv is None else argv)
    event = argv[0] if argv else ""
    try:
        payload = read_event(sys.stdin)
    except ValueError as error:
        print("гейт не выполнился: %s" % error, file=sys.stderr)
        return EXIT_OK

    handler = HANDLERS.get(event)
    if handler is None:
        print("гейт не выполнился: событие %s не обслуживается" % event,
              file=sys.stderr)
        return EXIT_OK
    return handler(payload)


HANDLERS = {}


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""Граница рабочего каталога: всё, что плагин меняет, лежит внутри корня.

Нормализация идёт **до** сравнения: `..`, симлинк и абсолютный путь обязаны
давать один и тот же ответ. Сравнение по префиксу строки без нормализации
ловится собственным `..` и потому не годится — та же ошибка, которую
`escapes_root` волны 1 уже один раз пережил.
"""

import os
from pathlib import Path

MARKER = ".twinkle-repo-builder"


def find_root(start):
    """Вверх от каталога до первого маркера, не выше git-корня.

    Граница взята из уже принятого: git обязателен (секция 8), значит корень
    контекстного репозитория не может лежать выше git-корня. Контекстный
    репозиторий при этом может жить вложенным внутри кодового.
    """
    current = Path(start).resolve()
    for candidate in [current, *current.parents]:
        if (candidate / MARKER).exists():
            return candidate
        if (candidate / ".git").exists():
            return None
    return None


def outside(path, root):
    """Лежит ли путь за корнем после полной нормализации.

    `os.path.realpath` разворачивает симлинки и схлопывает `..`; сравнение
    идёт по кортежу сегментов, а не по префиксу строки, иначе `repo-neighbour`
    считался бы лежащим внутри `repo`.
    """
    resolved = Path(os.path.realpath(str(path)))
    base = Path(os.path.realpath(str(root)))
    return resolved.parts[:len(base.parts)] != base.parts
```

- [ ] **Step 1: Написать падающий тест**

Тест собирает настоящий репозиторий-фикстуру и зовёт хук подпроцессом.

```python
import json
import os
import subprocess
import sys
import tempfile
import unittest
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
SHIM = ROOT / "hooks" / "hook.sh"


def make_repo(base):
    """Настоящий git-репозиторий с восемью зонами и маркером рецепта."""
    root = Path(base) / "repo"
    for zone in ("core", "areas", "projects", "knowledge",
                 "inbox", "sources", "tmp", "decisions"):
        (root / zone).mkdir(parents=True)
    (root / ".twinkle-repo-builder").write_text('{"version": "1"}',
                                                encoding="utf-8")
    subprocess.run(["git", "init", "-q"], cwd=str(root), check=True)
    return root


def call(event, payload, cwd):
    return subprocess.run([str(SHIM), event], input=json.dumps(payload),
                          capture_output=True, text=True, cwd=str(cwd))


class TestPreToolUseWrite(unittest.TestCase):
    def setUp(self):
        self._tmp = tempfile.TemporaryDirectory()
        self.root = make_repo(self._tmp.name)
        self.addCleanup(self._tmp.cleanup)

    def _payload(self, path):
        return {"hook_event_name": "PreToolUse", "cwd": str(self.root),
                "tool_name": "Write", "tool_input": {"file_path": str(path)}}

    def test_write_outside_root_is_blocked_and_names_the_boundary(self):
        outside = Path(self._tmp.name) / "elsewhere.md"
        result = call("PreToolUse", self._payload(outside), self.root)
        self.assertEqual(result.returncode, 2)
        self.assertIn("граница", result.stderr)
        self.assertIn(str(outside), result.stderr)

    def test_write_inside_root_passes_silently(self):
        result = call("PreToolUse", self._payload(self.root / "core" / "me.md"),
                      self.root)
        self.assertEqual(result.returncode, 0)
        self.assertEqual(result.stderr.strip(), "")

    def test_rewrite_in_core_warns_but_does_not_block(self):
        """Долгоживущий слой: предупреждение, не блок. Записи в `core` —
        содержимое, и автор в нём хозяин (линия ответственности)."""
        target = self.root / "core" / "me.md"
        target.write_text("уже есть\n", encoding="utf-8")
        result = call("PreToolUse", self._payload(target), self.root)
        self.assertEqual(result.returncode, 0)
        self.assertIn("core", result.stderr)

    def test_rewrite_in_sources_is_blocked(self):
        """Неизменяемость `sources` держит доказуемость всего производного:
        поправленный задним числом транскрипт делает недоказуемым каждый
        вывод, который на него ссылается. Это поломка, а не конвенция."""
        target = self.root / "sources" / "call.md"
        target.write_text("как получено\n", encoding="utf-8")
        result = call("PreToolUse", self._payload(target), self.root)
        self.assertEqual(result.returncode, 2)
        self.assertIn("sources", result.stderr)

    def test_new_file_in_sources_is_allowed(self):
        """Зона только для добавления: запрещена правка, не появление."""
        result = call("PreToolUse",
                      self._payload(self.root / "sources" / "new.md"), self.root)
        self.assertEqual(result.returncode, 0)

    def test_unparsed_tool_input_is_visible_and_not_a_block(self):
        """Имена полей `tool_input` не документированы. Не нашёлся путь —
        видимая строка и код 0: блокировать по собственной слепоте нельзя,
        молча пропускать тоже (незыблемое №4)."""
        payload = {"hook_event_name": "PreToolUse", "cwd": str(self.root),
                   "tool_name": "Write", "tool_input": {"неизвестно": 1}}
        result = call("PreToolUse", payload, self.root)
        self.assertEqual(result.returncode, 0)
        self.assertIn("путь не разобран", result.stderr)
```

"""Сканер команды Bash: что блокируем в терминале и что честно не ловим.

Порт зрелого куска: посимвольный разбор кавычек и сегментное сопоставление
путей (`journal/` совпадает, `journaling/` нет). Это защита от случайности,
не от намерения, и остаточный риск назван списком, а не умолчанием.
"""

BLOCKED = ("mv", "git mv")

# Явный список неперехватываемого. Записанный остаточный риск отличает
# бэкстоп от притворной песочницы: без него пользователь считает, что
# защищён, там где не защищён.
UNCATCHABLE = (
    "удаление и перемещение через python-скрипт, запущенный из Bash",
    "mv во временный каталог вне репозитория",
    "eval со строкой, собранной во время исполнения",
)

_SEPARATORS = ("&&", "||", ";", "|", "\n")


class Verdict:
    __slots__ = ("blocked", "reason")

    def __init__(self, blocked, reason=""):
        self.blocked = blocked
        self.reason = reason


def _strip_quoted(text):
    """Содержимое кавычек заменяется пробелами: длина и позиции сохраняются."""
    out = []
    quote = None
    escaped = False
    for ch in text:
        if escaped:
            out.append(" " if quote else ch)
            escaped = False
            continue
        if ch == "\\":
            escaped = True
            out.append(" " if quote else ch)
            continue
        if quote:
            out.append(" ")
            if ch == quote:
                quote = None
            continue
        if ch in "'\"":
            quote = ch
            out.append(" ")
            continue
        out.append(ch)
    return "".join(out)


def commands(line):
    """Первые слова всех сегментов команды, без содержимого кавычек."""
    clean = _strip_quoted(line)
    for sep in _SEPARATORS:
        clean = clean.replace(sep, "\n")
    out = []
    for part in clean.split("\n"):
        words = part.split()
        if words:
            out.append(words[0])
    return out


def touches_zone(line, zone_names):
    """Совпадение по сегменту пути, а не по префиксу строки."""
    clean = _strip_quoted(line)
    for token in clean.split():
        segments = token.strip("./").split("/")
        if segments and segments[0] in zone_names:
            return True
    return False


def judge(line):
    """Блокировать ли команду. В причине — имя правильного пути.

    Правильный путь называется командным токеном, а не backtick-путём:
    у контекстного репозитория нет своего `scripts/`, и backtick-путь сам
    поднял бы unresolved в гейте ссылок.
    """
    words = commands(line)
    clean = _strip_quoted(line).split()
    pair = " ".join(clean[:2]) if len(clean) >= 2 else ""
    if "mv" in words or pair == "git mv":
        return Verdict(True, "перемещение мимо скрипта ломает все входящие "
                             "ссылки. Правильный путь — команда move, она "
                             "переписывает ссылки и двигает файл одной "
                             "транзакцией")
    return Verdict(False)

    target = _path(root, session_id)
    if not target.parent.exists():
        return
    with target.open("a", encoding="utf-8") as handle:
        handle.write(rel_path + "\n")

    if not target.exists():
        return []
    return [line for line in target.read_text(encoding="utf-8").split("\n") if line]

"""Сводка старта сессии и чекпоинт незакоммиченного.

На диск не пишется ничего: сводка вычисляется и печатается в stdout, откуда
попадает в контекст. Вычисляемое не обязано лежать на диске — оно вычисляется,
а файл, перезаписываемый на каждом старте, ломает разводку «незакоммиченное
означает, что здесь работал человек».
"""

import subprocess
from pathlib import Path

from scripts import zones


def _git(root, *args):
    return subprocess.run(["git", *args], cwd=str(root),
                          capture_output=True, text=True)


def uncommitted(root):
    """Пути с незакоммиченными изменениями, относительные."""
    result = _git(root, "status", "--porcelain")
    out = []
    for line in result.stdout.split("\n"):
        if len(line) > 3:
            out.append(line[3:].strip())
    return out


def inbox_state(root):
    """Сколько элементов в inbox и возраст старшего в днях — из git, не из часов.

    Возраст берётся как разница между датой последнего коммита репозитория
    и датой первого коммита файла: обе даты приходят из git, поэтому отчёт
    остаётся воспроизводимым и не зависит от часов машины.
    """
    items = sorted(p for p in (Path(root) / "inbox").rglob("*.md"))
    return len(items)


def render(root):
    last = _git(root, "log", "-1", "--format=%ad", "--date=short").stdout.strip()
    dirty = uncommitted(root)
    lines = [
        "последний чекпоинт: %s" % (last or "нет коммитов"),
        "незакоммиченного: %s" % ("нет" if not dirty else "%d файлов" % len(dirty)),
        "inbox: %d" % inbox_state(root),
    ]
    return "\n".join(lines)


def checkpoint(root, paths):
    """`git add` только по названным путям. Никогда `-A`."""
    if not paths:

def on_stop(payload):
    """Синхронно: асинхронный хук не может задержать конец хода, а без
    задержки требование «красный ход не может закончиться» невыполнимо.

    `stop_hook_active` обязателен. Сверх него Claude Code сам перестаёт
    слушать после восьми блокировок подряд — но сдаваться на втором заходе
    наша работа, а не чужого предохранителя.
    """
    root = _root_of(payload)
    if root is None:
        print("гейт не выполнился: корень репозитория не найден", file=sys.stderr)
        return EXIT_OK

    dirty = set(summary.uncommitted(root))
    if not dirty:
        return EXIT_OK

    mine = set(turnfiles.listing(root, payload.get("session_id", "")))
    findings = []
    for gate in (check_links, check_frontmatter):
        findings.extend(f for f in gate.scan(root).findings if f.path in dirty)
    if not findings:
        return EXIT_OK

    ours = [f for f in findings if f.path in mine]
    theirs = [f for f in findings if f.path not in mine]

    if theirs:
        print("правлено вне сессии и сломано — починить?")
        print("\n".join(f.render() for f in theirs))

    if ours and not payload.get("stop_hook_active"):
        print("ход не заканчивается: файлы этого хода сломаны", file=sys.stderr)
        print("\n".join(f.render() for f in ours), file=sys.stderr)
        return EXIT_VIOLATION
    return EXIT_OK


HANDLERS["Stop"] = on_stop
