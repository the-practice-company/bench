# twinkle-repo-builder

Плагин Claude Code, который создаёт, усыновляет и поддерживает **контекстные
репозитории** — не кодовые, а для ведения домена: компания, проект, найм,
личная жизнь. Внутри markdown, Obsidian как фронтенд для человека, Claude Code
как агент.

Сам этот репозиторий — обычный кодовый: здесь живёт пакет плагина.

## Проверка

```sh
./check
```

Тесты и проверка пакета, один код возврата на всё. Другой команды проверки нет
и заводить её не надо.

## Незыблемые

1. **Линия ответственности.** Форму правит плагин молча, содержимое не трогает
   без автора. Ни одна волна не расширяет плагину права на содержимое.
2. **Нет проверки — нет гейта.** Правило существует, только будучи выражено
   исполняемой проверкой. Объявить проверку, за которой нет кода, нельзя.
3. **Эффективность, а не маскарад.** Механизм не заводится, пока не предъявлена
   наблюдённая поломка, которую он чинит.
4. **Запрет молчаливых заглушек.** Невосстановимое значение либо помечается
   синтетическим, либо уходит в отчёт. Никогда не подставляется тихо — ни в
   полях записей, ни в ответах за автора.
5. **Ноль зависимостей.** Python stdlib, git, файловая система. Ни MCP, ни
   внешних движков, ни сети — ни в гейтах, ни в хуках, ни в скриптах.
6. **Граница рабочего каталога.** Плагин не пишет и не двигает ничего вне корня
   репозитория. Исключения ровно два, оба названы в секции 15 спеки.
7. **Спека — источник истины.** Разошлись реализация и спека — правится спека
   отдельным коммитом, а не код втихую.

## Как здесь работают

Цикл superpowers: `brainstorming` → `writing-plans` → `executing-plans` →
`requesting-code-review` → `finishing-a-development-branch`. Реализация идёт по
TDD: падающий тест раньше кода, всегда.

Тесты утверждают **точный список** находок — класс, путь, строка, деталь, — а
не «что-то нашлось». Проверка, которая не краснеет на посаженном нарушении, не
считается проверкой: это правило уже один раз остановило закрытие волны 1.

Две вещи эскалируются автору всегда:

- **правка спеки.** Незыблемое №7 требует править её, а не код, — но что именно
  поправить, решает автор. Агент приносит расхождение и предложение.
- **отказ от механизма, записанного в спеке, по мотиву «не понадобилось».**
  Не заводить неизмеренное — можно. Вынимать уже обоснованное — нельзя без
  автора.

Остальные обратимые решения агент принимает сам, примерно на 70% информации,
которую хотелось бы иметь: ждать полноты на обратимом решении — это медленно,
а не осторожно.

## Не переоткрывать

Три места, где «очевидная починка» ломает то, что уже разобрано. У каждого
есть история.

- **`escapes_root(target, base)`: `base` — путь ссылающегося файла, не его
  каталог.** Разводит эти два чтения ровно один тест,
  `tests/test_paths.py::test_dotdot_above_root_escapes`. Из
  `areas/hiring/README.md` ссылка `../../core/me.md` даёт `False` — переход
  между зонами законен, — а `../../../outside.md` даёт `True`. Ревью один раз
  уже называло это блокером по ошибке; второй раз «чинить» обратно нельзя.
- **Периметр backtick-сканирования — `CLAUDE.md`, `README.md`, `SKILL.md` и
  `.claude/rules/*.md`, дословно по спеке.** Расширение на все markdown-файлы
  было откачено: оно давало 27 ложных `escapes-root` на этом же репозитории.
  Из ужатия признака пути сохранено ровно одно: токен с пробелом внутри —
  командная строка, а не путь.
- **`unresolved` на битой фикстуре — 5.** Число росло дважды, и каждый раз
  образец клали намеренно: четвёртый — `areas/hiring/items/` в
  `.claude/rules/areas.md` (rule-файл, указывающий на переименованную папку),
  пятый — `[[projects/dup]]` в `areas/hiring/pathlink.md`, который разводит
  резолв по пути и запрещённый откат на basename: `dup.md` в дереве есть,
  но не по этому пути. Сверять число здесь глазами больше не нужно:
  `tests/test_gate_coverage.py::TestTableCountsMatchTheGates` роняет набор,
  если таблица покрытия разошлась с выводом гейта. Уменьшать его «обратно»
  без снятого образца нельзя — это и есть та починка, ради которой заведена
  эта секция.

## Открытые вопросы

- Спека велит считать ошибкой слэш-команды и маршруты API в backtick'ах
  (`/baton:auto 1`, `/backlinks/:path`). Подтвердить это поведение или править
  таблицу признака пути — спека, секция 13, «Что backtick-токен считается
  путём». Номер строки здесь стоял и протух: в живом документе на 2888 строк
  ссылка на строку — обещание, которое ломается от любой правки выше по
  тексту. До ответа гейт работает ровно как написано.
- Три решения спеки, оспоренные аудитом: скелет CLAUDE.md (§9), нечем
  фальсифицировать рецепт (§27), отказ от сигналов протухания (§24, §27).
  На время прогона 2026-08-28 автор делегировал их агенту: решать по существу,
  а не буквально по спеке. Разошёлся — правит спеку с обоснованием в трекере.

Три решения волны 1 — закрытое множество матчеров, чтение «any absolute path»,
судьба `--today` — автором утверждены как записаны и больше не открыты.
